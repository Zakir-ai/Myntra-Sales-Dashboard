# 🛍️ Myntra Sales Dashboard Project

This project presents an interactive **Sales Dashboard** created using **Power BI**, based on Myntra's e-commerce sales data. It provides a comprehensive view of sales performance across categories, regions, customer demographics, and time periods.

---

## 🧰 Tools Used

- 📊 **[Power BI](https://powerbi.microsoft.com/desktop/)** — for building the dashboard and visualizations  
- 🐍 **[Python (Pandas)](https://www.python.org/downloads/)** — used for additional data cleaning or transformation if needed  
- 📑 **[Microsoft Excel](https://www.microsoft.com/en-in/microsoft-365/excel)** — initial data structuring and cleaning
  
---

## 📂 Files Included

- `Myntra_Sales_Dashboard.pbix` — Power BI dashboard file  
- `Myntra dataset.xlsx` — Cleaned and structured dataset containing:
  - `fact_orders` — Order transaction data (Order ID, Date, Quantity, Sales)
  - `dim_products` — Product details (Product ID, Category, Sub-Category)
  - `dim_customers` — Customer demographics (Customer ID, City, Age, Gender, Region, Tier)

## 📈 Dashboard Features

- 📅 **Line Chart** — Monthly Sales Trend  
- 📍 **Bar Chart** — Sales by Region  
- 🧵 **Donut Chart** — Sales by Product Category  
- 🎛️ **Slicer/Filter** — Filter data by Category  
- 🎨 **Color Highlights** — Emphasize top-performing areas  
- 📌 **KPI Cards** — Show key business metrics  

---

## 🔍 Key Insights

1. **North Region** generated the highest sales, contributing 42% of total revenue.
2. The **Electronics** category led the market with $450K in sales.
3. **December** saw a sales peak, indicating high year-end demand.
4. **Customers aged 25–34** made the most purchases, especially during festive seasons.
5. **Repeat customers** contributed 65% of total orders—highlighting strong brand loyalty.
6. **Delhi** topped in transactions, followed by Mumbai and Bangalore.
7. **Tier-2 cities** like Jaipur and Indore showed rising order trends, indicating growing market reach.
